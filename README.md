# locator 
Web-прототип акустичного локатора
https://dimon-qrz.github.io/locator.html/
📋 Інструкція з виконання калібрування:Крок 1 (Запуск та розміщення):Увімкніть мікрофони у висувних списках та натисніть кнопку «1. Ініціалізувати аудіоканали».За допомогою повзунків «Позиція на радарі (°)» виставте фізичний кут розміщення мікрофонів відносно вашого робочого місця ($0^\circ$ — прямо перед вами, $90^\circ$ — праворуч, $270^\circ$ — ліворуч).Крок 2 (Калібрування затримки Bluetooth/USB):Джерело звуку: Використовуйте монотонне клацання (наприклад, ритмічне клацання пальцями біля мікрофона або дзвоник).Піднесіть джерело звуку впритул до M1 (Вебкамера/Провідний) — ви побачите стрибок рівня сигналу M1.Тепер піднесіть таке ж джерело звуку впритул до M2 (Bluetooth). Через бездротовий протокол ви помітите апаратне запізнення в реакції.Повзунком «Компенсація затримки (мс)» біля M2 додайте затримку для швидшого мікрофона (або налаштуйте інтервал так), щоб показники сили сигналу та розрахованого азимута моментально й симетрично реагували на звук з відповідної сторони.Крок 3 (Запуск пеленгації):Натисніть «2. Запустити Сканування Пеленгатора». Стрілка червоного кольору показуватиме точний кут на джерело звуку з урахуванням вирівняної часової затримки.
